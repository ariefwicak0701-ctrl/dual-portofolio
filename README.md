# Dual Portof

Satu proyek portfolio, **dua desain berbeda**, dan **dua profil terpisah** dalam satu repository.

## 📋 Tentang Proyek

Proyek ini berisi dua tampilan portfolio yang berbeda. Setiap tampilan menampilkan profil yang berbeda dengan bio, skill, dan proyek miliknya masing-masing.

## 🎨 Dua Desain

| Desain | Profil | File Utama |
|--------|--------|------------|
| Desain 1 | [FEIRA] | `design-1/index.html` |
| Desain 2 | [IDUNN] | `design-2/index.html` |

## 📂 Struktur Folder

💡 Sesuaikan dengan folder asli proyekmu ya.
🚀 Cara Menjalankan
Proyek ini tidak perlu instalasi. Cukup buka file index.html di browser:
1. Download atau clone repository ini
2. Buka folder dual-portof
3. Klik dua kali file index.html
4. Pilih desain yang ingin dilihat
Atau kalau pakai VS Code, install ekstensi Live Server, klik kanan index.html → Open with Live Server.
